## Project Overview

AlphaGalData is a Gatsby 5 site for people managing alpha-gal syndrome. It combines educational MDX content, recipe publishing, downloadable emergency assets, a client-side ingredient scanner, and county/state tick-distribution maps. The app is statically built and deployed to S3 behind CloudFront, with Terraform covering AWS hosting, Cognito, and inbound email forwarding.

## Quick Reference

- **Tech Stack:** Gatsby 5, React 18, TypeScript, MDX, Tailwind CSS, Leaflet, Decap CMS, Cognito OIDC, Terraform
- **Entry Point:** `src/pages/index.tsx`
- **Architecture Pattern:** static content site plus browser-only interactive feature islands
- **Data:** JSON and GeoJSON files under `src/data/` and `static/data/`, MDX content under `content/`
- **Deployment:** `scripts/deploy_s3.sh` to S3/CloudFront; Terraform in `tf/`
